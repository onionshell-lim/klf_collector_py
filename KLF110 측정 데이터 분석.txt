1. CSV 파일 3개를 읽는다.
1-1. CSV 파일을 읽을 때 각 라인의 첫번째 항목이 날자가 아니면 주석으로 처리한다.
1-2. 데이터 항목 이름과 순서는 주석 라인 중 "순서:" 다음에 정의된대로 처리한다.

2. 읽은 데이터를 Machine Learning 학습하고 펌프 개수를 추론한다
2-1. 데이터 항목 이름 중에서 "Real-time velocity", "Avg. velocity"의 시계열 특성을 입력으로 사용한다. 
2-2. "펌프" 데이터 항목 숫자를 레이블로 사용한다. 숫자는 펌프 갯수이다. 숫자가 0 이어도 "Real-time velocity", "Avg. velocity" 값이 출력되는 이유는 노이즈 때문이다.
2-3. 학습:검증:평가 데이터 갯수 비율은 3:1:1 로 한다.
2-4. "Real-time velocity", "Avg. velocity" 시계열 특성을 이용해서 노이즈인 경우("펌프" 가 0)를 구별할 수 있도록 학습한다.
2-5. 추론 모델은 RNN 모델을 1차적으로 사용한다.Transform 모델등 다른 모델을 사용하는 것도 허용한다.
2-6. RNN 모델의 시퀀스 갯수를 변경하면서 정확도를 판정해서 최적 시퀀스 갯수를 결정한다
2-7. 매번 선택한 시퀀스 데이터 들은 -1.0~1.0 사이로 노멀라이즈해서 사용한다. DC 성분은 제거한다.
2-8. 학습 도중 검증 결과와 최종 평가 결과를 매 epoch 마다 출력한다.
2-9. 먼저 100 epoch 를 시도하고, 횡축을 epoch 정확도를 종축하는 그래프를 그린다.
2-10. 그래프등 결과들은 이 창에서 바로 보여준다.

3. "펌프" 가 1,2 인 경우의 데이터로부터 조도를 추론한다.
3-1. 데이터 항목 이름 중에서 "Real-time velocity", "Avg. velocity"," Water level"(수위) 시계열 특성을 이용한다.
3-2. 추론 모델은 RNN 모델을 1차적으로 사용한다.Transform 모델등 다른 모델을 사용하는 것도 허용한다.
3-3. RNN 모델의 시퀀스 갯수를 변경하면서 정확도를 판정해서 최적 시퀀스 갯수를 결정한다
3-4. 매번 선택한 시퀀스 데이터 들은 -1.0~1.0 사이로 노멀라이즈해서 사용한다. DC 성분은 제거한다.
3-5. 동일한 수로 환경이므로 조도도 같은 값이다. 속도만 다르다.
3-6. 학습:검증:평가 데이터 갯수 비율은 3:1:1 로 한다.
3-7. 학습 도중 검증 결과와 최종 평가 결과를 매 epoch 마다 출력한다.
3-8. 먼저 100 epoch 를 시도하고, 횡축을 epoch 정확도를 종축하는 그래프를 그린다.  
3-9 그래프등 결과들은 이 창에서 바로 보여준다.
